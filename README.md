# lightning-project
Temporal variation of lightning, CAPE and AOD

## Overview

This repository contains a representative Python analysis workflow developed as part of my thesis research.

The notebook demonstrates:

- Loading NetCDF datasets using xarray
- Harmonizing spatial and temporal coordinates
- Interpolating datasets onto a common spatial grid
- Computing spatial averages and monthly climatologies
- Producing publication-quality scientific visualizations with Matplotlib

## Repository Contents

- `lightning_CAPE_AOD monthly variation.ipynb` – Python notebook for analysing the temporal variation of Lightning, CAPE and Aerosol Optical Depth (AOD).

## Note

The original datasets are **not included** because they form part of ongoing thesis research and are not publicly distributable.

To execute the notebook, replace the placeholder dataset paths with the appropriate NetCDF files.
